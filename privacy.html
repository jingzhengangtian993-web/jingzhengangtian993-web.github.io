プライバシーポリシー

Keima Secretary（以下「本アプリ」）は、開発者本人が自分の Mac の中だけで使う個人用のアプリです。

取得する情報

本アプリは、利用者が許可した場合に限り、Google カレンダーの予定（タイトル・日時など）を読み取り専用の権限（calendar.events.readonly）で取得します。

情報の使い方

取得した予定は、利用者の Mac の中で、本アプリの画面にその日の予定を表示するためだけに使います。

保存と第三者への提供

  • 予定のデータと Google の認証情報は、利用者の Mac の中（認証情報は macOS のキーチェーン）にだけ保存します。
  • 取得した Google のデータを、第三者へ提供・販売・送信することはありません。
  • 広告や、AI モデルの学習には使いません。

Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

アクセスの取り消し

利用者は Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本アプリのアクセスを取り消せます。
